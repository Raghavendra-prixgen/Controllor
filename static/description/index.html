DevOps & Multi-Tenant Fleet

Odoo Fleet Control Connector

Connect, monitor, deploy, and manage your Odoo.sh-style multi-project fleet directly from Odoo UI using Personal API Tokens and RBAC.

Key Capabilities

🔑 Personal API Token & RBAC

Each operator configures their personal access token in their User Profile. Token roles (Admin, Developer, Viewer) automatically sync with Odoo security groups.

🚀 1-Click Multi-Project Fleet

Inspect production environments, container uptime, database health, Traefik hostnames, and trigger production builds with a single click.

🌿 Ephemeral Staging Branches

Branch out staging environments on demand directly from Git branches. Clean up and destroy staging containers when PR testing is done.

💾 DB Backups & Overwrite Restore

Snapshot databases before risky upgrades, download binary dumps, and restore backups to main or staging with built-in safety confirmations.

🛡️ Sandbox Neutralizer

Prevent accidental customer emails and live charges on staging. Neutralize mail servers and force payment gateways to test mode in one click.

🩺 AI Diagnostics & Quick-Fix

Automated diagnosis of XML ParseErrors, KeyError dependencies, duplicate IDs, and instant execution of automated remediation fixes.

Quick Setup Guide

  1. Navigate to Settings > Fleet Control and configure your Fleet Platform Base URL (e.g. http://127.0.0.1:8000).
  2. Open your User Preferences or Settings > Users > [Your User] > Fleet Platform Access.
  3. Paste your Personal API Token (e.g. admin-secret-prixgen-key or pxg_usr_...) and click Verify Token & Sync Rights.
  4. Open the Fleet Control Room menu to view and manage all projects, staging branches, builds, and backups!
